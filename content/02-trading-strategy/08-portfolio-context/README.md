# 模块 08: 账户结构与持仓检查

## 描述

这个模块学习聚宽平台的账户结构和持仓管理。核心内容包括：

- `context.portfolio` 账户对象的结构和属性
- `context.portfolio.positions` 持仓字典的用法
- 用持仓状态驱动交易逻辑
- 回测环境的完整设置（手续费、滑点、基准、成交量限制、真实价格模式）
- 不同调度频率（run_daily vs run_monthly）对策略行为的影响
- 为什么同样代码在不同环境下回测结果可能不同

本模块合并了源文件 `2_simple_trade_strategy_jq.py` 和 `3_simple_trade_strategy_jq.py` 的学习内容。

## 重要说明

本模块代码为 **聚宽（JoinQuant）平台策略脚本**，不能直接在本地 Python 环境中运行。代码依赖聚宽平台提供的策略引擎、数据接口和下单系统。

学习方式：阅读代码和注释，理解策略逻辑和平台 API，而非本地运行。

## 前置知识

- Python 基础语法
- 了解聚宽策略基本结构（initialize / market_open）
- 建议先学习模块 07（MA 均线交叉策略）

## 策略逻辑概要

1. 选择股票：000001.XSHE（平安银行）
2. 设置回测环境：沪深 300 基准、手续费、滑点、成交量限制、真实价格模式
3. 每天 9:30 执行：
   - 如果没有持仓 -> 买入 1000 股
   - 如果有持仓 -> 卖出 800 股
4. 实际节奏：买入 -> 卖出 800 -> 卖出剩余 -> 重新买入，约三天一个周期

## 学完能做什么

- 理解 `context.portfolio` 和 `context.portfolio.positions` 的结构
- 能用持仓状态驱动交易决策
- 理解 `order()`、`order_value()`、`order_target()` 三种下单方式的区别
- 理解手续费、滑点、成交量限制等回测环境设置的金融含义
- 理解回测结果差异的原因
- 为后续学习更复杂的持仓管理打下基础
