# 模块 10: 回测可复现性

## 这个模块学什么

系统学习聚宽策略的账户结构，理解 portfolio（总账户）和 subportfolio（子账户）的关系，掌握账户状态的关键字段。这些知识是理解回测可复现性的基础。

核心知识点：
- portfolio 与 subportfolio 的层级关系
- 总权益、累计收益率、初始资金的计算逻辑
- 可用资金、可取资金、冻结资金的区别
- 为什么不同人的回测结果会不同

## 为什么学这个

量化研究的核心原则之一是"可复现"。如果你的策略跑出来赚了 2%，别人复制你的代码却得到 1.5%，那这个结果就不可信。理解账户结构和回测参数，才能让别人复现你的结果，也才能公平地比较不同策略。

## 运行环境

本模块代码为聚宽（JoinQuant）平台策略代码，不能在本地直接运行。需要：
- 注册聚宽账号：https://www.joinquant.com
- 在聚宽"策略研究"中新建策略
- 将 `main.py` 代码粘贴到聚宽编辑器中运行

## 文件说明

| 文件 | 用途 |
|------|------|
| `main.py` | 原始聚宽策略代码，可直接粘贴到聚宽平台运行 |
| `explained.py` | 详细注释版，逐行解释代码含义，适合学习阅读 |
| `notes.md` | 学习笔记，账户结构详解、回测可复现性说明 |
| `README.md` | 本文件，模块导读 |
| `output/` | 输出说明目录（本模块无本地输出） |
