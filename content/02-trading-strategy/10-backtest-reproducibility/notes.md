# 模块 10: 回测可复现性

## 今天学什么

本模块学习聚宽策略的账户结构，理解 portfolio（总账户）和 subportfolio（子账户）的关系，掌握账户状态的关键字段。这些知识是理解"为什么不同人的回测结果不同"以及"如何让回测可复现"的基础。

核心问题：你的策略跑出来赚了 2%，别人复制你的代码跑出来可能是 1.5%，为什么？

## 核心概念

### Portfolio（总账户）vs Subportfolio（子账户）

这是聚宽账户体系的核心结构：

- **portfolio**：像"整个家庭总账本"，反映账户的整体状态
- **subportfolios[0]**：像"家庭总账本下面的某一个具体账户"，反映子账户的细节

两者的关系：
```
portfolio.total_value = sum(各 subportfolio 的总权益)
```

### 为什么回测结果会不同？

不同人运行同一段策略代码，得到不同结果，常见原因有：

1. **起始时间不同**：从 2020 年开始和从 2022 年开始，市场环境完全不同
2. **初始资金不同**：10 万和 100 万的交易行为可能不同（比如仓位分配）
3. **交易成本设置不同**：有没有设置佣金、印花税、滑点
4. **数据源差异**：不同平台的历史数据可能有细微差别
5. **复权方式不同**：前复权、后复权、不复权，结果差异很大
6. **随机性因素**：某些策略用到随机数，没有固定种子

### 如何让回测可复现？

1. **固定起始时间**：明确写明回测区间
2. **固定初始资金**：在策略中明确设置
3. **设置交易成本**：使用 `set_order_cost` 和 `set_slippage`
4. **记录所有参数**：把关键参数写在代码注释或配置文件中
5. **使用相同的复权方式**：在数据获取时明确指定

## 关键 API / 函数

### `context.portfolio` 总账户对象

| 字段 | 含义 |
|------|------|
| `total_value` | 账户总权益（现金 + 持仓市值） |
| `returns` | 累计收益率 = (当前总权益 - 初始资金) / 初始资金 |
| `starting_cash` | 初始资金 |
| `positions_value` | 当前持仓总市值 |
| `long_positions` | 多头持仓集合（股票通常只有多头） |
| `short_positions` | 空头持仓集合（A 股学习阶段通常为空） |

### `context.subportfolios[0]` 子账户对象

| 字段 | 含义 |
|------|------|
| `available_cash` | 当前可用于下单的现金 |
| `transferable_cash` | 可转出的资金（不一定等于可用资金） |
| `locked_cash` | 被挂单锁住、暂时冻结的现金 |
| `inout_cash` | 累计出入金（不是收益） |
| `type` | 账户类型 |

### 数学关系

```
总权益 = 可用现金 + 持仓市值 + 其他现金项
累计收益率 = (当前总权益 - 初始资金) / 初始资金
```

举例：
- 初始资金 = 100,000
- 当前总权益 = 102,000
- 收益率 = (102,000 - 100,000) / 100,000 = 2%

## 代码解读

### 第一步：初始化

```python
def initialize(context):
    g.security = "000001.XSHE"  # 交易标的：平安银行
```

只设置了交易标的，没有设置基准、交易成本等。这在初学阶段可以，但正式回测时应该补全。

### 第二步：简单买卖逻辑

```python
if g.security not in context.portfolio.positions:
    order(g.security, 1000)   # 没持仓就买
else:
    order(g.security, -800)   # 有持仓就卖
```

这是一个"买 1000 股 -> 卖 800 股 -> 买 1000 股 -> 卖 800 股"的循环。

### 第三步：输出账户信息

```python
print(context.portfolio.total_value)        # 总权益
print(context.portfolio.returns)            # 累计收益率
print(context.portfolio.starting_cash)      # 初始资金
print(context.subportfolios[0].available_cash)  # 可用资金
print(context.subportfolios[0].locked_cash)     # 冻结资金
```

这些字段帮助你实时监控账户状态，是做仓位管理和风控的基础。

## 学习心得

1. **账户结构比想象中复杂**。刚开始学交易，以为只要知道"买了多少、卖了多少"就够了。实际上，账户里有总权益、可用资金、冻结资金、持仓市值等多个维度，每个都有用。

2. **available_cash 和 transferable_cash 不一样**。这个区别很重要：有些钱虽然可以用来下单，但不能马上转出。这在真实交易中会遇到。

3. **locked_cash 不是"消失的钱"**。很多初学者看到可用资金比预期少，以为是亏了，其实可能只是被挂单冻结了。

4. **inout_cash 不是收益**。它只是记录你历史上转入转出了多少钱，和投资收益是两码事。

5. **理解账户结构是做风控的前提**。以后做更复杂的策略时，你需要根据 available_cash 决定下单量，根据 locked_cash 判断是否有未成交的挂单，根据 returns 判断策略表现。
