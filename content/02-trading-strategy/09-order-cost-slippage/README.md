# 模块 09: 交易成本与滑点设置

## 这个模块学什么

理解交易系统中"下单"和"成交"的区别，学会通过成交记录（Trade）验证实际交易结果，为设置交易成本和滑点打下基础。

核心知识点：
- 订单（Order）与成交记录（Trade）的区别
- `get_trades()` 获取成交记录
- 成交时间与订单关联
- 交易成本和滑点的基本概念

## 为什么学这个

在量化回测中，如果不考虑交易成本和滑点，回测结果往往过于乐观。真实交易中每次买卖都有佣金、印花税等费用，实际成交价也可能和预期不同。理解这些概念，才能让回测结果更接近真实情况。

## 运行环境

本模块代码为聚宽（JoinQuant）平台策略代码，不能在本地直接运行。需要：
- 注册聚宽账号：https://www.joinquant.com
- 在聚宽"策略研究"中新建策略
- 将 `main.py` 代码粘贴到聚宽编辑器中运行
