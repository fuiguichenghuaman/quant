# 模块 09: 交易成本与滑点设置

## 今天学什么

本模块学习交易系统中"下单"和"成交"的区别，以及如何通过成交记录（Trade）来验证实际交易结果。这是理解交易成本和滑点概念的基础。

核心问题：你下单买了 1000 股，市场真的给你成交了 1000 股吗？成交的价格是你预期的价格吗？

## 核心概念

### 订单（Order）vs 成交记录（Trade）

这是两个完全不同的概念，很多初学者容易混淆：

- **订单（Order）**：你发给市场的"交易请求"。就像你在外卖软件上点了一份餐。
- **成交记录（Trade）**：市场真正撮合成功之后形成的结果。就像骑手真的接单并送达了。

关键区别：
- 下单不等于成交
- 一笔订单可能分多次成交
- 成交价格可能和你下单时看到的价格不同（这就是"滑点"）

### 交易成本

真实交易中，每次买卖都有成本：
- **佣金**：券商收取的手续费
- **印花税**：卖出时国家收取的税费
- **过户费**：股票过户时的费用

在回测中如果不考虑这些成本，回测结果会比真实交易好看很多。

### 滑点（Slippage）

滑点是指你预期的成交价格和实际成交价格之间的差异。比如：
- 你想在 10.00 元买入
- 但实际成交价是 10.02 元
- 这 0.02 元就是滑点

滑点在流动性差的股票、大额交易、市场剧烈波动时尤其明显。

## 关键 API / 函数

### `order(security, amount)`
- 作用：下单函数
- `security`：股票代码，如 `'000001.XSHE'`
- `amount`：正数买入，负数卖出
- 返回：订单对象

### `get_trades()`
- 作用：获取当天所有成交记录
- 返回：类似字典结构，需要用 `.values()` 遍历
- 注意：返回的是"已成交"的记录，不是"已下单"的记录

### `_trade.time`
- 作用：成交发生的时间
- 用途：分析成交时机，判断是否在预期时间成交

### `_trade.order_id`
- 作用：这条成交记录对应的订单编号
- 用途：把成交记录和原始订单关联起来
- 注意：一笔订单可能对应多条成交记录

## 代码解读

### 第一步：初始化设置

```python
def initialize(context):
    set_benchmark('000300.XSHG')  # 设定业绩基准为沪深300
    g.security = '000001.XSHE'    # 交易标的：平安银行
    run_daily(market_open, time='9:30')          # 每天开盘执行
    run_daily(after_market_close, time='15:30')  # 每天收盘后执行
```

`run_daily` 是聚宽的定时调度函数，让你的策略在指定时间自动执行。

### 第二步：开盘交易逻辑

```python
def market_open(context):
    if g.security not in context.portfolio.positions:
        order(g.security, 1000)   # 没持仓就买1000股
    else:
        order(g.security, -800)   # 有持仓就卖800股
```

这是一个简单的"买-卖-买-卖"循环策略。

### 第三步：收盘查看成交记录

```python
def after_market_close(context):
    trades = get_trades()
    for _trade in trades.values():
        print("成交记录：{}".format(_trade))
        print("成交时间：{}".format(_trade.time))
        print("对应的订单id：{}".format(_trade.order_id))
```

这一步是本模块的核心：通过 `get_trades()` 查看当天真正成交了什么。

## 学习心得

1. **下单和成交是两回事**。在真实市场中，你下了单不代表一定成交，成交了也不一定按你想要的价格。这个概念对理解交易成本至关重要。

2. **成交记录比订单更重要**。如果你想分析策略的真实表现，必须看成交记录，而不是只看下了什么单。

3. **为后续学习打基础**。理解了订单和成交的区别之后，下一步自然会想知道：成交价格和预期价格差多少（滑点）？每次交易花了多少手续费（交易成本）？这些都会直接影响策略的真实收益。

4. **回测和实盘的差距**。很多看起来很好的策略，加上交易成本和滑点之后就不行了。所以越早理解这些概念越好。
