# 模块 07: MA 均线交叉策略

## 描述

这是交易策略系列的第一个模块。使用 MA5（5 日均线）作为买卖信号：当价格高于均线 1% 时买入，跌回均线下方时卖出。

这是最简单的量化策略入门案例，帮助你从"学指标"过渡到"用指标做交易决策"。

## 重要说明

本模块代码为 **聚宽（JoinQuant）平台策略脚本**，不能直接在本地 Python 环境中运行。代码依赖聚宽平台提供的策略引擎、数据接口和下单系统。

学习方式：阅读代码和注释，理解策略逻辑和平台 API，而非本地运行。

## 策略逻辑概要

1. 选择股票：000001.XSHE（平安银行）
2. 每个交易日执行：
   - 计算最近 5 天收盘价的平均值（MA5）
   - 如果当前价 > MA5 * 1.01 -> 用全部可用现金买入
   - 如果当前价 < MA5 且有持仓 -> 清仓卖出
3. 记录当前价格用于回测观察
