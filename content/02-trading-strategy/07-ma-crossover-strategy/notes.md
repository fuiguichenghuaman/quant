# 模块 07: MA 均线交叉策略

## 今天学什么

这是交易策略系列的第一个模块。前面我们学了各种技术指标（MACD、KDJ、均线等），但那些都是"分析工具"——它们帮你看出股票的状态，但不会告诉你"该不该买"。

这个模块开始进入"策略"的世界：用 MA5（5 日均线）作为判断依据，当价格明显高于均线时买入，跌回均线下方时卖出。

简单说：从"看指标"进化到"用指标做决策"。

## 核心概念

### 什么是均线交叉策略

均线（Moving Average，简称 MA）是把最近 N 天的收盘价求平均，得到一个"平均价格"。这个平均价格每天都会变，连起来就是一条线。

策略逻辑很简单：
- 价格在均线之上，说明最近走势偏强 -> 考虑买入
- 价格在均线之下，说明最近走势偏弱 -> 考虑卖出

这里的"交叉"不是指两条均线交叉，而是价格和均线之间的交叉关系。

### 策略脚本 vs 分析脚本

前面学的代码大多是"分析脚本"——读数据、算指标、画图。这份代码是"策略脚本"——它不只分析，还要做决策、下单。

核心区别：
- 分析脚本：输入数据 -> 输出图表/数值
- 策略脚本：输入市场状态 -> 输出买卖动作

### 聚宽平台策略的运行方式

这份代码不是你从上往下运行一遍就结束的普通脚本。它的运行方式是：

1. 聚宽平台先读取代码
2. 调用 `initialize(context)` 做一次初始化
3. 之后按你注册的规则，反复调用 `market_open(context)`

这就像一个"事件驱动"的程序：平台是事件源，你的代码是响应函数。

| 对象 | 作用 | 备注 |

## 代码解读

### initialize 阶段

```python
def initialize(context):
    g.security = '000001.XSHE'
    run_daily(market_open, time='every_bar')
```

做了两件事：
1. 把要交易的股票（平安银行，深交所）存到全局变量
2. 告诉平台：每个 bar 时点都执行一次 `market_open`

### market_open 阶段

每次被调用时，按顺序做这些事：

1. **取数据**：拿到最近 5 天收盘价
2. **算均线**：5 天收盘价的平均值 = MA5
3. **取当前价**：最近一天的收盘价
4. **取可用现金**：从平台账户对象里读
5. **判断买卖**：
   - 如果当前价 > MA5 的 1.01 倍 -> 用全部可用现金买入
   - 如果当前价 < MA5 且有可卖仓位 -> 清仓卖出
6. **记录价格**：方便回测后画图观察

### 买入条件解读

```python
if current_price > 1.01 * MA5:
```

意思是"当前价格比 5 日均线高出 1%"。为什么要高出 1% 而不是刚好高于就买？这是一个简单的"过滤噪音"设计——价格刚好在均线附近时容易来回穿越，加一个小门槛可以减少频繁交易。

### 卖出条件解读

```python
elif current_price < MA5 and context.portfolio.positions[security].closeable_amount > 0:
```

两个条件同时满足才卖出：
- 价格跌回均线下方
- 手里确实有股票可以卖

第二个条件很重要——如果你没有持仓，执行卖出指令会出问题。

## 学习心得

这个模块虽然代码很短，但它是从"学习分析"到"学习策略"的分水岭。有几个点值得记住：

1. **平台代码和本地代码是两回事**。这份代码里的 `attribute_history`、`order_value`、`context.portfolio` 这些都不是 Python 自带的，而是聚宽平台提供的。在 VS Code 里直接运行会报错，这不是代码写错了，而是运行环境不对。

2. **策略的核心逻辑其实很简单**。均线之上买、均线之下卖——一句话就能说清。但真正做量化交易时，难点不在于策略逻辑有多复杂，而在于执行细节：手续费怎么算、滑点怎么处理、仓位怎么管理。

3. **`close_data['close'][-1]` 在不同环境里行为可能不同**。在聚宽平台里通常能拿到最后一个值，但在普通 pandas 里，`[-1]` 可能被理解成标签索引而不是位置索引。这是平台代码的一个典型"看起来像 Python 但不完全是 Python"的地方。

4. **买入用全部现金是一种极简写法**。真实策略会做更细的仓位管理，比如只用 30% 的资金买入，留 70% 做防守。但作为入门学习，先理解"有信号就操作"的逻辑更重要。
