# 学习笔记：MACD 指标

## 核心概念

### 什么是 MACD？

MACD（Moving Average Convergence Divergence，移动平均收敛散度）是最常用的技术指标之一。它由三部分组成：

- **DIF（快线）**：短期 EMA 减去长期 EMA，反映短期趋势与中期趋势的差异
- **DEA（信号线）**：DIF 的 EMA 平滑值，更平滑，用来和 DIF 配合判断
- **BAR（柱状图）**：(DIF - DEA) x 2，用柱子的高低表示两条线的差距

### MACD 的参数

标准参数是 12、26、9：

| 参数 | 含义 | 默认值 |
|------|------|--------|
| `fastperiod` | 快线 EMA 周期 | 12 |
| `slowperiod` | 慢线 EMA 周期 | 26 |
| `signalperiod` | DEA 平滑周期 | 9 |

这组参数是 Gerald Appel 提出的经典配置，大多数行情软件默认使用这组值。

### DIF、DEA、BAR 的关系

```
DIF = EMA(12) - EMA(26)     # 快线减慢线
DEA = EMA(DIF, 9)           # DIF 的平滑线
BAR = (DIF - DEA) x 2       # 两线差距的柱状表现
```

- DIF 比 DEA 高得多 -> 柱子又高又红（多方强）
- DIF 比 DEA 低得多 -> 柱子又高又绿（空方强）
- DIF 和 DEA 接近 -> 柱子很短（多空平衡）

### 指数移动平均（EMA）

EMA 是"指数加权移动平均"，和 SMA（简单移动平均）的区别是：

- SMA：最近 N 天的权重相同，"一视同仁"
- EMA：最近的权重更大，越早的权重越小，"越近越重要"

用 `pandas` 的 `.ewm(span=N).mean()` 可以直接计算 EMA。

## 生活化例子

### 用跑步理解 DIF 和 DEA

想象两个人在跑步：

- **短跑选手**（DIF）：跑得快，反应灵敏，但容易受干扰
- **长跑选手**（DEA）：跑得慢，但更稳，不容易受短期波动影响

当短跑选手突然加速时，他和长跑选手的距离（DIF）会拉大。
但长跑选手也会慢慢加速跟上（DEA 是 DIF 的平滑）。

所以：
- DIF 快速变化，像短跑选手的即时速度
- DEA 变化更慢，像长跑选手的平均速度
- BAR 像两人之间的距离差

### 用天气理解 MACD

假设你在观察一个城市的温度：

- 12 日 EMA：最近 12 天的平均温度（更敏感）
- 26 日 EMA：最近 26 天的平均温度（更稳定）

当天气开始变暖时：
- 12 日 EMA 会先升高
- 26 日 EMA 慢慢跟上
- DIF（两者之差）从 0 变成正数
- 柱子从绿色变成红色

当天气开始变冷时：
- 反过来，DIF 变负，柱子变绿

## 容易出错的地方

### 1. 把工具函数当成完整流程函数来调用

```python
calc_macd()          # 错！没有传 df
calc_macd(df)        # 对！先有 df，再调用
```

`calc_macd()` 是工具函数，必须先准备好 DataFrame 再传进去。

### 2. 忘记 CSV 没有表头

```python
pd.read_csv(file, header=None)  # 必须有 header=None
```

如果漏掉，第一行真实数据会被当成列名。

### 3. close 列不是数字

如果 CSV 里的收盘价是字符串格式（比如带了引号或特殊字符），MACD 计算会出问题。需要确保 `close` 列是数值类型。

### 4. `(dif - dea) * 2` 为什么乘 2

这是很多行情软件的惯例，让柱子更明显。有些软件不乘 2，有些乘 1，看你用哪个标准。学习阶段用 `* 2` 就行。

### 5. 服务器环境用 plt.show()

`plt.show()` 需要 GUI 环境，服务器上会报错。应该用 `plt.savefig()` 保存为文件。

### 6. 中文字体设置

```python
plt.rcParams["font.sans-serif"] = ["SimHei"]
```

如果服务器上没有 SimHei 字体，中文会显示成方块。可以改成服务器上有的字体，或者用英文标题。

## 固定写法与可修改部分

### 不要随便改的固定写法

```python
import pandas as pd
from pathlib import Path

df["close"].ewm(span=fastperiod, adjust=False).mean()  # EMA 计算
df["date"] = pd.to_datetime(df["date"])                 # 日期转换
df_macd = calc_macd(df)                                 # 先有 df，再调用
```

### 可以根据需求改的参数

| 参数 | 含义 | 示例 |
|------|------|------|
| `DATA_FILE` | 数据文件路径 | 换成别的 CSV 就读别的数据 |
| `fastperiod=12` | 快线 EMA 周期 | 改成 8 更敏感 |
| `slowperiod=26` | 慢线 EMA 周期 | 改成 17 更敏感 |
| `signalperiod=9` | DEA 平滑周期 | 改成 7 更敏感 |
| `color="red"` | DEA 线颜色 | 可改成任何颜色 |
| `color="blue"` | DIF 线颜色 | 可改成任何颜色 |
| `width=0.5` | 柱子宽度 | 改大更粗 |
| `rotation=30` | 横坐标倾斜角度 | 改成 45 更斜 |

## MACD 常见用法（了解即可，不构成投资建议）

### 金叉和死叉

- **金叉**：DIF 从下向上穿过 DEA，柱子从绿变红
- **死叉**：DIF 从上向下穿过 DEA，柱子从红变绿

这只是技术分析的一种观察方式，不保证准确性。

### 柱状图的变化

- 柱子由短变长：趋势在加强
- 柱子由长变短：趋势在减弱
- 柱子翻转（红变绿或绿变红）：趋势可能反转

这些只是描述性的观察，不构成买卖信号。
