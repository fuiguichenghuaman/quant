# 综合技术指标图

## 这个模块学什么

把前面学过的多个技术指标整合到一张图里：

- K 线图（蜡烛图）+ 均线（MA5、MA10）
- 成交量柱状图
- MACD 指标（DIF、DEA、BAR）
- KDJ 指标（K、D、J）

四个区域上下排列，共用横坐标日期，形成一张完整的"股票体检报告"。

## 为什么学这个

实际做量化分析时，你不会只看一个指标。K 线看形态、均线看趋势、成交量看热度、MACD 看动能、KDJ 看区间位置——把它们放在一张图里，才能全面了解一只股票的状态。这个模块就是把前面学过的知识串起来。

## 学完能做什么

- 能把多个技术指标整合到同一张图里
- 能用 subplots 创建多区域图表
- 能用 candlestick2_ochl 画 K 线图
- 能理解"工具函数"和"完整流程函数"的代码组织方式
- 为后续做复盘、策略观察、公开展示打下基础

## 前置知识

- Python 基础语法
- pandas 基本操作
- matplotlib 基本画图
- 了解 K 线、均线、MACD、KDJ 的基本概念

```bash
pip install pandas matplotlib mplfinance

```
