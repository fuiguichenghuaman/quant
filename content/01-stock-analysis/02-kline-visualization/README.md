# K 线图可视化

## 这个模块学什么

用 matplotlib 和 mplfinance 绘制股票 K 线图，并叠加成交量和均线：

- 基础 K 线图（蜡烛图）
- 带成交量的 K 线图
- 带成交量和 5/10 日均线的 K 线图
- A 股红涨绿跌配色

## 为什么学这个

量化学习不能只会算数，还要会从图上观察价格结构。K 线图是金融分析中最基础的可视化工具，几乎所有技术分析、策略回测、研究报告都会用到它。

学完这个模块，你就能把 CSV 里的数字变成直观的图表，看到价格的涨跌、成交量的变化、均线的趋势。

## 学完能做什么

- 能用 Python 画出标准的 K 线图
- 理解 K 线的四个核心价格（开、收、高、低）
- 能在 K 线图上叠加成交量和均线
- 理解 A 股红涨绿跌的配色规则
- 为后续学习指标可视化和回测图表打下基础

## 前置知识

- Python 基础语法（变量、函数、列表）
- 了解 pandas 的 DataFrame 基本操作
- 了解 CSV 文件格式

建议先完成 [NumPy 股票数据基础](../01-numpy-basics/) 模块。

## 文件说明

## 运行方式

```bash
cd content/01-stock-analysis/02-kline-visualization
pip install pandas matplotlib mplfinance
python main.py
```

运行后会在 `output/` 目录下生成三张 K 线图。
