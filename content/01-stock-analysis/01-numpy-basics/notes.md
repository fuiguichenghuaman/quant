# 学习笔记：NumPy 股票数据基础

## 核心概念

### 什么是 NumPy？

NumPy 是 Python 最常用的数值计算库。你可以把它理解成一个"数字工具箱"——当你需要处理一大堆数字（比如几百天的股票收盘价）时，NumPy 比纯 Python 快得多，写起来也更简洁。

固定写法：`import numpy as np`，看到 `np` 基本就是 NumPy。

### 什么是移动平均线？

移动平均线（Moving Average）是量化分析里最基础的指标之一。

- **SMA（简单移动平均线）**：最近 N 天的收盘价，每天权重相同，直接求平均。
- **EMA（指数移动平均线）**：最近 N 天的收盘价，越近的权重越大，对新价格更敏感。

## 生活化例子

### 用 7 天价格理解 SMA

假设 7 天收盘价：`[10, 11, 12, 13, 14, 15, 16]`

算 5 日均线（MA5）：

- 第一个 MA5：(10 + 11 + 12 + 13 + 14) / 5 = **12**
- 第二个 MA5：(11 + 12 + 13 + 14 + 15) / 5 = **13**
- 第三个 MA5：(12 + 13 + 14 + 15 + 16) / 5 = **14**

结果：`[12, 13, 14]`

为什么前 4 天没有 MA5？因为 MA5 必须凑够连续 5 天，前 1~4 天数据不够。

### 为什么用卷积计算？

`np.convolve()` 就像一个"滑动窗口"——让一个小窗口沿着价格数组滑动，每滑动一次做一次加权求和。对于 SMA 来说，每次求和就是"最近 5 天的价格之和 / 5"。

### SMA 和 EMA 的区别

- SMA：5 个权重都是 0.2，"一视同仁"
- EMA：权重是 `[0.1, 0.12, 0.15, 0.23, 0.4]` 这样的递增数组，"越近越重要"

## 容易出错的地方

### 1. Python 区分大小写

`N` 和 `n` 是两个不同的变量。写错大小写会报 `NameError`。

### 2. 列号从 0 开始

`usecols=(2, 6)` 读的是第 3 列和第 7 列，不是第 2 列和第 6 列。这是 Python 的索引规则，初学者很容易搞混。

### 3. `(2)` 不是元组

在 Python 里，`(2)` 等价于整数 `2`，不是元组。单元素元组的正确写法是 `(2,)`。不过 `np.loadtxt` 允许传单个整数，所以 `(2)` 也能正常运行。

### 4. `plt.show()` vs `plt.savefig()`

- `plt.show()` 弹出图形窗口——只在有 GUI 的电脑上有效
- `plt.savefig()` 保存为图片文件——服务器环境必须用这个

### 5. 卷积结果要截取

`np.convolve()` 返回的结果前后包含"不完整窗口"的边缘值，必须用 `[N-1:-N+1]` 切掉，否则结果不准确。

### 6. 编码问题

Windows 下的 CSV 文件有时带 BOM 头，用 `encoding="utf-8-sig"` 可以避免乱码。如果还是报错，试试 `"utf-8"` 或 `"gbk"`。

### 7. 变量名拼写

源代码里 `annual_volatitly` 和 `mothly_volatitly` 是拼写错误，正确写法是 `annual_volatility` 和 `monthly_volatility`。代码能跑，但写代码要注意拼写规范。

## 固定写法与可修改部分

### 不要随便改的固定写法

```python
import numpy as np
import matplotlib.pyplot as plt
from pathlib import Path

np.loadtxt(...)          # 参数名 fname=、delimiter=、usecols=、encoding= 都是 numpy 规定的
plt.savefig(...)         # 服务器环境用这个，不要用 plt.show()
```

### 可以根据需求改的参数

| 参数 | 含义 | 示例 |
|------|------|------|
| `DATA_FILE` | 数据文件路径 | 换成别的 CSV 就读别的数据 |
| `usecols=(2, 6)` | 读取哪几列 | 改成 `(1, 3)` 就读别的字段 |
| `N = 5` | 均线窗口长度 | 改成 10 就是 MA10，20 就是 MA20 |
| `linewidth=2` | 线条粗细 | 只影响图表美观，不影响计算 |
| `np.sqrt(250)` | 年化交易日数 | 250 是 A 股近似值，美股用 252 |
