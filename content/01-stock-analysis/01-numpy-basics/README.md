# NumPy 股票数据基础

## 这个模块学什么

用 NumPy 读取股票 CSV 数据，并完成一系列基础统计计算：

- 读取收盘价、成交量、最高价、最低价
- 最大值、最小值、极差
- 平均值、成交量加权平均价（VWAP）、中位数、方差
- 对数收益率与波动率
- 5 日简单移动平均线（SMA）
- 5 日指数移动平均线（EMA）

## 为什么学这个

量化交易的底层是数据。不管你以后用多复杂的策略，第一步都是把价格数据读进来、算出基本指标。NumPy 是 Python 数据分析的基础库，掌握它之后再学 pandas、回测框架会轻松很多。

## 学完能做什么

- 能用 Python 读取任意 CSV 格式的股票数据
- 能计算常见的统计指标（均值、中位数、方差、波动率）
- 能自己写出 SMA 和 EMA 的计算逻辑
- 能用 matplotlib 把指标画成图表
- 为后续学习策略设计和回测打下基础

## 前置知识

- Python 基础语法（变量、函数、列表）
- 会用终端 / 命令行运行 Python 脚本
- 了解 CSV 文件格式

如果这些还不熟，建议先补一下 Python 入门。

## 运行方式

```bash
cd content/01-stock-analysis/01-numpy-basics
pip install numpy matplotlib
python main.py
```

运行后会在 `output/` 目录下生成 SMA 和 EMA 的图表。
