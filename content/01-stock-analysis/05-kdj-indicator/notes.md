# 学习笔记：KDJ 指标

## 核心概念

### 什么是 KDJ？

KDJ 是一种技术指标，用来观察价格在最近一段区间里的相对位置和波动节奏。它由三条线组成：

- **K 线**：比较快的线，对 RSV 做一次平滑
- **D 线**：更平滑一点的线，对 K 再做一次平滑
- **J 线**：更敏感、更容易波动的线，由 K 和 D 推算得出

### KDJ 的计算步骤

1. 计算最近 9 天的最低价和最高价（rolling 窗口）
2. 计算 RSV = (当前收盘价 - 9天最低价) / (9天最高价 - 9天最低价) * 100
3. K = RSV 的指数加权平均
4. D = K 的指数加权平均
5. J = 3*K - 2*D

### rolling 窗口和 expanding 窗口

- `rolling(9)`：固定窗口长度为 9，每次看最近 9 天
- `expanding()`：从开头一直扩展到当前，第 1 天看 1 天，第 2 天看 2 天

当数据不够 9 天时，用 expanding 的值来填补 NaN。

### 工具函数 vs 完整流程函数

- `cal_kdj(df)` 是"工具函数"：不自己读文件，只负责接收 df 并算出 KDJ
- `plot_kdj()` 是"完整流程函数"：自己读文件、准备数据、调用工具函数、画图

## 生活化例子

### 用考试成绩理解 RSV

假设最近 9 次考试：
- 最低分：60
- 最高分：95
- 你这次考了：85

RSV = (85 - 60) / (95 - 60) * 100 = 71.4

这说明你这次成绩在最近 9 次里偏上。

### 用温度理解 K、D、J

- RSV 就像"今天的实际温度"
- K 就像"今天穿了薄外套后的体感温度"（平滑一次）
- D 就像"今天穿了厚外套后的体感温度"（再平滑一次）
- J 就像"风一吹就变的体感温度"（更敏感）

## 容易出错的地方

### 1. 把工具函数当成完整流程函数来调用

`cal_kdj()` 需要先传入 `df`，不能直接空着调用。

### 2. 忘记 CSV 没有表头

如果漏掉 `header=None`，第一行真实数据会被当成列名。

### 3. 忘记 high、low、close 这三列必须是数字

否则 KDJ 计算会出问题。

### 4. 前 8 天不够 9 天窗口时会出现缺失值

如果不做 `fillna()` 处理，前面结果会更不完整。

### 5. K、D、J 三条线含义不同

不要把它们当成同一条线，只是颜色不同。

### 6. 服务器环境不能用 plt.show()

必须用 `plt.savefig()` 保存为图片文件。

## 固定写法与可修改部分

### 不要随便改的固定写法

```python
import pandas as pd
import matplotlib
matplotlib.use("Agg")  # 服务器环境必须加
import matplotlib.pyplot as plt

rolling(9, min_periods=9)      # KDJ 标准窗口
fillna(value=..., inplace=True) # 补缺失值
pd.to_datetime(df["date"])      # 日期转换
ewm(com=2).mean()               # 指数加权平均
```

### 可以根据需求改的参数

| 参数 | 含义 | 示例 |
|------|------|------|
| `DATA_FILE` | 数据文件路径 | 换成别的 CSV 就读别的数据 |
| `rolling(9, ...)` | 观察区间长度 | 改成 14 就是 14 天窗口 |
| `com=2` | 平滑程度 | 影响 K 和 D 的平滑程度 |
| `color="red"` 等 | 线条颜色 | 只影响图表美观 |
| `figsize=(12, 6)` | 图表大小 | 只影响图表美观 |
